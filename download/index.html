ARIA Remote

L'agent Windows qui permet à ARIA de se connecter à ce PC — toujours avec ton accord.

remote-agent.exe Version __VERSION__ · Windows 64 bits · __SIZE__
Télécharger

Pour démarrer

  1. Lance remote-agent.exe. Une fenêtre s'ouvre.
  2. Saisis l'adresse du serveur et la clé de l'agent, qui t'ont été fournies. Elles sont retenues.
  3. Un code à 6 chiffres s'affiche : saisis-le dans ARIA, onglet Ordinateur › Maintenance à distance.
  4. Chaque prise de contrôle te demande ton accord. Tu peux la couper à tout moment.

Windows affiche un avertissement ?

Le fichier n'est pas encore signé par un éditeur reconnu : SmartScreen peut le signaler. Compare d'abord son empreinte (ci-dessous), puis clique sur Informations complémentaires › Exécuter quand même.
