ARIA Remote

Contrôler un PC à distance ·

Connexion au serveur

Saisis l'adresse de ton serveur de rendez-vous et la clé du contrôleur. Elles sont retenues sur ce PC : tu ne les saisiras qu'une fois.

Appareils

    Aucun appareil pour l'instant. Lance l'agent sur le PC à contrôler (télécharge-le sur processxen.com), puis saisis à droite le code à 6 chiffres qu'il affiche.

    Ajouter un appareil

    Saisis le code d'appairage affiché par l'agent sur l'autre PC.

    Pas de code ? Si l'agent indique « Prêt à être contrôlé », l'appareil est déjà appairé : il est dans la liste. Sinon, utilise le bouton « Afficher un code d'appairage » de l'agent.
